# saf.gmsh.lite

Coarser-resolution gmsh-meshed (C_mesh=3) reproduction of the Southern San
Andreas Fault system from Liu et al. (2022) Model A. Companion to
`paper.saf.A` (C_mesh=2 reference).

## Loading inputs (origin)

Per-node γ (max shear strain rate) and φ (compression angle) are
interpolated onto the gmsh fault nodes from a tight pair of files copied
in from `paper.saf.A/`:

- `Rate_direction.txt` — paper's per-node loading (rad/s, deg)
- `x1_1.txt`, `x2_1.txt`, `x3_1.txt` — paper's fault control points

These four must travel together — `Rate_direction.txt` rows are keyed to
the per-fault node positions generated by spline-sampling `x*_1.txt` at
paper's `dxy = 200 m`. `meshgen.py` rebuilds those positions in Python
(via `loadPaperRateDirAlongArcLen`) and uses them as the source for
arc-length interpolation onto the local gmsh nodes.

## Fault system

Three independent right-lateral strike-slip faults (ftType=-1, ftDip=90):
- `ssaf` — Southern San Andreas Fault (80 control points, single trace)
- `sjfn` — San Jacinto Fault North Strand (15 control points)
- `sjfs` — San Jacinto Fault South Strand (10 control points)

All control points come from `user_fault_geometry_input/{ssaf,sjfn,sjfs}.gmt.txt`
(cols 1–2 = x, y in km; cols 3–4 are unused — superseded by paper interpolation).

## Mesh + loading flow

1. `meshgen.py` reads .gmt control points.
2. Builds natural cubic spline y(x) per fault (mirrors `meshgen1.f90`).
3. gmsh meshes 2D domain with embedded fault polylines; element size `dx=0.4 km`.
4. For every gmsh fault node:
   - tangent = analytical spline derivative (smooth, no chord kinks).
   - per-node loading interpolated from `paper.saf.A/Rate_direction.txt` along arc-length.
5. Writes `fem_mesh_output/{vert,fac,nsmp,nsmpGeoPhys,nsmpTanLen,meshGeneralInfo}.txt`.
6. `case.setup` writes FE_*.txt and run.sh.

## Loading encoding (paper-faithful)

`nsmpGeoPhys.txt` per-node values (with paper-faithful interpretation):

| Col | Field | saf.gmsh.lite value |
|---|---|---|
| 6 | ftLoadMaxShear (γ) | per-node from paper Rate_direction.txt col 1 |
| 7 | ftLoadAngle (φ) | per-node from paper Rate_direction.txt col 2 |
| 8 | ftLoadWt | constant 450 |
| 9 | ftVis | per-node = `ant0·str/γ` (= paper's `ant`) |

`interstress.f90` C_mesh=3 branch then computes  
`ant = ftVis·450/ftLoadWt = ant0·str/γ`,  
matching paper.saf.A's interstress formula exactly.

## Files

```
user_defined_params.py            # case parameters
userDefinedFaultSysGeoPhys.py     # base ftPhys row template
meshgen.py                        # gmsh + paper-loading interp
user_fault_geometry_input/
  ssaf.gmt.txt                    # SAF control points
  sjfn.gmt.txt                    # SJFN control points
  sjfs.gmt.txt                    # SJFS control points
README.md
```

`meshGenLib.py` is **not** in this dir — it's the canonical copy from
`scripts/meshGenLib.py` and is copied in by `create.newcase`.

## Usage

```bash
create.newcase --work_dir work/saflite --compset saf.gmsh.lite
cd work/saflite
python3 meshgen.py
python3 case.setup
bash run.sh
```

## Resolution comparison

| | paper.saf.A | saf.gmsh.lite |
|---|---|---|
| Mesh | C_mesh=2 (Fortran structured quad) | C_mesh=3 (gmsh) |
| dxy | 200 m | 400 m |
| Fault nodes (sjfn/sjfs/ssaf) | 295 / 178 / 1769 | ~158 / ~95 / ~959 |
| Cycle 1 first interval | 471 yr | 473 yr |
| Cycle 1 magnitude | M5.74 | M5.7 |
